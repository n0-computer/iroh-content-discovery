iroh content links

Links on *.blake3.net and *.pkarr.net open content from peers over iroh, through a gateway running on your own machine.

How the links work

A link like https://<hash>.blake3.net/file names content by its BLAKE3 hash. Your local gateway finds a peer that has the content, fetches it directly from them, and checks it against the hash, so it doesn't matter who serves it.

A link like https://<key>.pkarr.net/ names a public key. The key's owner publishes a signed pkarr record saying what the name points to, and can update it at any time. Your gateway looks up the record, verifies the signature, and opens the content it points to.

blake3.net and pkarr.net never see these requests: the browser extension sends the links straight to the gateway on your machine. Without the extension and gateway, the links don't open.

Get started

  1. Install the gateway. It runs in the background.
  2. Install the iroh link browser extension for Chrome or Brave or Firefox.
  3. Open a blake3.net or pkarr.net link, for example:
    • A collection of public domain content by hash
    • The same collection by public key
