Connect your browser to Iroh Gateway

The gateway runs in the background on port 8080. The extension redirects blake3.net and pkarr.net links to it. Install the extension manually; the installer does not change browser settings.

Chrome or Brave

  1. Open chrome://extensions or brave://extensions.
  2. Enable Developer mode, then choose Load unpacked.
  3. Select the chrome folder beside this instructions file.
  4. Open the extension popup and save port 8080 with redirects enabled.

Firefox

Firefox 140 or later is required. In regular Firefox, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select firefox/manifest.json beside this file. This installation lasts until Firefox restarts.

For a permanent unsigned installation, use Firefox Developer Edition, Nightly, or ESR. Set xpinstall.signatures.required to false in about:config, then open about:addons, choose the gear menu's Install Add-on From File, and select iroh-link-firefox-unsigned.xpi beside this file.

In the extension popup, click Save and grant access to blake3.net and pkarr.net. Regular Firefox requires a Mozilla-signed package for permanent installation. See Mozilla's signing documentation.

Where are these files?

Windows: %LOCALAPPDATA%\Programs\Iroh Gateway\extensions.
macOS: ~/Applications/Iroh Gateway Extensions.

Keep the Chrome folder in place while the unpacked extension is installed. After upgrading the gateway, reload the extension on the browser's extensions page. Remove the extension manually when uninstalling the gateway.

If links do not work

Make sure the gateway is running and the extension port matches. Only one application can listen on port 8080; a running Blobtorrent gateway uses the same port. Stop that gateway or configure a different port before starting this one.

Gateway settings and logs are in %LOCALAPPDATA%\iroh-local-gateway on Windows or ~/Library/Application Support/iroh-local-gateway on macOS. gateway.log records discovery and HTTP activity; launcher.log records startup errors. To change the port, stop the gateway and put ["--listen", "127.0.0.1:8081"] in arguments.json. Restart it and set the same port in the extension. On macOS, run the app's iroh-gateway-background install-agent helper to update login arguments.
